隱私權政策

最後更新:2026-10-04

這個應用程式是什麼

「Aletheia」是一個個人專案的自動化工具,用來經營 YouTube 頻道「Aletheia 真實引擎」: 上傳影片、讀取觀眾留言、以及回覆留言。它只由頻道擁有者本人使用,不對外開放註冊。

會存取哪些資料

  • YouTube 帳戶授權:經由 Google OAuth 取得,用於上傳影片、讀取與回覆頻道留言、以及調整留言的審核狀態。
  • 公開留言內容:包括留言文字、留言者的公開顯示名稱與留言 ID。

資料怎麼被使用

留言內容會送交 AI 模型分類(判斷是提問、建議、批評或垃圾訊息)並草擬回覆。 回覆一律由人工審核後才送出。留言資料僅用於改進本專案公開的提示詞協議。

資料儲存在哪裡

授權憑證與留言紀錄只存放在頻道擁有者本人的電腦上,不上傳至任何伺服器,不公開,不販售, 也不與第三方分享。公開的測評報告只會包含彙整後的統計,不含個別留言者的身分資訊。

資料保留與刪除

留言紀錄保留到不再需要為止。若你希望移除你的留言資料,可直接在 YouTube 刪除該留言, 或透過下方聯絡方式告知。

第三方服務

本工具使用 YouTube Data API(適用 Google 隱私權政策) 與 Anthropic Claude API 進行留言分類。

聯絡方式

透過 GitHub Issues 或 YouTube 頻道 @AletheiaTW 聯絡。
