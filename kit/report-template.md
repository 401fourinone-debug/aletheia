# 回報格式

複製下面整段，填好後貼到 GitHub Issues（https://github.com/401fourinone-debug/aletheia/issues）或 YouTube 留言。
**請先拿掉個人資料。**

```
【題目】(missions.md 的編號,或你自己的問題原文)

【AI 與模型】(例:ChatGPT / GPT-4o、Claude / Sonnet、Gemini / 2.5 Pro)

【沒用協議的回答】(貼上,太長可以只貼關鍵段落)

【用了協議的回答】(貼上)

【哪一個比較好】A 沒協議 / B 有協議 / 差不多

【有沒有幫助】1 2 3 4 5   (1 = 協議讓它變糟,3 = 沒差,5 = 明顯更好)

【一句話說明】(例:有協議那次變得很長,但沒有回答我真正的問題)
```

## 打分參考

- **5**：明顯更好，而且好在內容（更誠實、更有用），不只是格式更多。
- **3**：差不多，或只是換了排版。
- **1**：變糟——更囉嗦、更冷、繞圈、該回答的沒回答、或反而編造了東西。

給 1 分的回報最重要，請不要不好意思。
