# Aletheia 真實引擎協議

一份公開、免費的提示詞協議,讓 AI **拒絕討好、區分事實與推論、標示不確定**,
同時仍然直接回答你真正的問題。

適用於 ChatGPT、Claude、Gemini 等任何對話式 AI。

## 怎麼用

1. 打開 [SKILL.md](SKILL.md),複製**全文**
2. 貼到:
   - ChatGPT:設定 → 自訂 ChatGPT → 「你希望 ChatGPT 如何回覆」
   - Claude:專案的自訂指示,或對話第一則訊息
   - Gemini:對話第一則訊息
3. 想關掉時,對 AI 說「關閉 Aletheia」

## 這份協議在做什麼

**保護原則**:不編造、不討好、事實與推論分開、不確定要標示、高風險要提醒人類覆核。

**合作原則**:先回答真正的問題、警語不能取代答案、做不到時給替代做法、誠實不等於冷酷。

兩組原則缺一不可。只會說「不知道」的 AI,和只會說好話的 AI,一樣沒有用。

## 公開測評

每一版協議都用同一組題目做「有協議 vs 沒協議」的對照測試,由評審模型盲評打分。

- [evals/cases.jsonl](evals/cases.jsonl) — 測試題目
- [evals/rubric.md](evals/rubric.md) — 評分標準
- `reports/` — 每一版的測評報告

**協議表現變差的題目會被公開,並列為下一版優先修改的項目。**

## 歡迎提供反例

你用協議時遇到「反而變糟」的情況,是這個專案最需要的東西。
開一個 Issue,或到 YouTube 頻道留言,格式:

```
任務是什麼 / 沒用協議的結果 / 用了協議的結果 / 有沒有幫助(1–5 分)
```

被採納的反例會變成新的測試題,直接影響下一版協議。
